# 浮島工坊

以桌面瀏覽器直接開啟 index.html，等待載入後按「開始探索」。遊戲使用本機 three.js 與原像素材質，不需伺服器、帳號或網路。需支援 WebGL。重新整理不自動載入世界，請使用 ESC 選單載入保存資料。

## 操作

| 操作 | 按鍵 |
|---|---|
| 前後左右 | W / S / A / D |
| 跳躍 | 空白鍵 |
| 蹲下、慢走與邊緣保護 | 左 Ctrl |
| 向前奔跑 | 左 Shift＋W |
| 轉向 | 滑鼠；未鎖定時移到左右邊緣可持續轉向，移回中央停止 |
| 挖掘 | 按住左鍵，放開取消 |
| 放置 | 右鍵；需有物品，合法位置有半透明預覽 |
| 選物品 | 1～9 或滾輪，保留點選快捷欄 |
| 暫停/設定/存檔 | ESC |
| 拍照模式 | P 進入或退出 |
| 拍攝 PNG | 拍照模式內按 O |

固定世界 32³，八種方塊加第九格空手，初始背包為零。挖掘後在原處掉落，靠近本格或八方位相鄰一格並處於相近高度才拾取；放置成功扣一，最遠互動五格。挖掘葉 1.5、沙 1.7、土 1.8、草 2、木板 2.4、原木 2.6、石頭/磚塊 3 秒，十階裂痕隨進度顯示。

十顆愛心；墜落 4 格扣 2、5 格扣 5、6 格扣 6，10 格以上致死。最後受傷等待 20 秒後，每 1.5 秒回一顆（首顆為 21.5 秒）；暫停不計時。死亡背包散落八方向一/二格內，滿血安全隨機復活；虛空採最後落腳處散落。

## 隨機效果、音效與天空

每 30～60 遊戲秒隨機一種、持續 20 秒，名稱與倒數位於準心下方。加速/減速為水平移動 1.5/0.5 倍，跳高比正常多三格（有少量離散物理誤差）；致盲三格內漸暗、三格外全黑。跳高仍適用墜落傷害。

一天 600 遊戲秒，天空循環日間、夕陽、夜間、黎明；致盲時覆蓋黑色，到期回復當時天空。音效由程式合成，八種材質有不同挖掘/放置/腳步音；開始手勢後啟用，ESC 可切靜音。瀏覽器不支援音效時遊戲仍可玩。

## 保存、載入與備份

ESC 選單中填 1～48 字世界名稱後「保存世界」，從清單選取後可載入、以名稱欄內容重新命名、匯出 JSON。保存包含世界方塊、背包、掉落物、血量、玩家位置/視角、遊戲時間與隨機效果。

本機最多 20 個存檔，儲存在目前瀏覽器的 localStorage，其他瀏覽器/設定檔或移動檔案後不保證共享；請保留匯出備份。清除瀏覽器網站資料可能移除保存資料。空間不足會提示未完成，不假稱成功。

「匯入備份」接受最大 2 MB JSON，先驗證格式、數值與出生點後新增到清單，再按載入。錯檔不會部分覆蓋目前世界。匯出只是備份，不會刪除原存檔。

## 拍照與 photosave

P 進入獨立相機模式，玩家與世界時計凍結；WASD 移動、滑鼠轉向，長按空白上飛、左 Ctrl 下飛。雙擊空白（300 ms 內、不計鍵盤 repeat）取消飛行並快速落地，仍留在拍照模式；P 退出回原玩家鏡頭，再進可重新飛行。拍照移動不傷害玩家或改背包。

O 擷取畫布 PNG，不含 HUD、準心、選取框或放置預覽。首次拍照若瀏覽器支援資料夾選擇，請選 mcgame（會建立 photosave）或直接選 photosave（不會重複多建一層）。同一分頁後續照片復用目錄權限；不支援或寫入失敗時下載 PNG，請手動移入 mcgame/photosave。取消目錄選擇則不拍照、不強制下載。

瀏覽器顯示授權對話框可能使遊戲暫停；完成後可按「繼續探索」。不能未經你授權任意寫入本機位置。photosave 的 PNG 已排除 Git 追蹤。
