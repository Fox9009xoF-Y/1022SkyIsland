# 浮島工坊

直接開啟本資料夾的 index.html，按「開始探索」。本次沿用並修改既有 index.html、style.css、game.js、check.cjs 與文件，沒有另建遊戲專案。素材與 three.js 皆留在本機，不需安裝、網路、帳號或後端。瀏覽器必須支援 WebGL。

## 操作

| 操作 | 按鍵 |
|---|---|
| 前後左右 | W / S / A / D |
| 跳躍 | 空白鍵 |
| 蹲下、慢走與邊緣保護 | 左 Ctrl |
| 向前奔跑 | 左 Shift＋W |
| 轉向 | 移動滑鼠，十字準心固定在正中央 |
| 挖掘 | 按住左鍵，放開取消進度 |
| 放置 | 右鍵，有物品才能放置 |
| 選擇物品 | 1～9、滑鼠滾輪，也保留點選快捷欄 |
| 暫停 | ESC，失焦也會暫停 |

第一次開啟物品數量為零。靠近掉落物所在格或八方位相鄰一格會自動拾取；需在相近高度。八種方塊分別佔一格，第九格為空手。

## 遊戲規則

世界儲存在固定 32 × 32 × 32 範圍內，隨機產生草地、沙子、石頭與樹木。挖掉的方塊先變成可見掉落物，落在附近地面，並非直接加入物品欄。拾取增加數量，放置成功扣一；不能放入自己身體或世界邊界外。

挖掘與放置射線最遠 5 格。樹葉挖掘 1.5 秒、沙子 1.7 秒、泥土 1.8 秒、草地 2 秒、木板 2.4 秒、原木 2.6 秒、石頭與磚塊 3 秒。裂痕隨進度分十階顯示；放開左鍵、換目標或暫停就重設進度。

滿血十顆心。實際落差未滿 4 格不扣血，4 格扣 2 顆、5 格扣 5 顆、6 格扣 6 顆，依此類推，最多扣到零。落差由空中最高的腳底位置到落地位置計算。最後一次受傷後等待 20 秒，再每 1.5 秒回復一顆（第一顆於受傷後 21.5 秒回復），暫停不推進計時。

死亡會將每種非零物品以一疊的形式，隨機散落在死亡格八方位的 1 或 2 格處，每疊保留全部數量；背包清空，玩家在可站立的隨機位置滿血復活。墜入虛空也視為死亡，物品散落在最後落腳處附近。若世界完全沒有可復活位置，會補一格草地作為安全落腳處。

暫停選單提供全螢幕、畫質切換及重新生成島嶼。重新生成會清空物品與掉落物並恢復滿血；重新整理、關閉頁面不保留進度。

## 瀏覽器相容性與效能

遊戲會嘗試鎖定滑鼠，提供連續轉向；不支援或遭拒絕時仍可進入，改用畫面內滑鼠移動轉向。相容模式下，將滑鼠移至畫面左右邊緣即可持續轉向，停止移動滑鼠也能轉過多圈；移回中央區域或按 ESC 可停止邊緣轉向。鎖定成功時使用原本的相對位移轉向，不額外套用邊緣旋轉。系統游標在遊戲中隱藏，中央準心始終固定。

僅建立外露表面並合併地形；掉落物採批次繪製，無陰影與後處理。省電模式先使用像素比 1，若連續偵測低 FPS 會逐步降低內部解析度至 50%，顯示尺寸仍保持全螢幕。左上角顯示 FPS。舊電腦及僅 CPU 繪圖的全螢幕 30 FPS 尚未實測，無法保證。

## 隨機效果開發進度

依新增 BRIEF 分步實作，已完成 E01 排程與 E02 加速/減速：每 30～60 秒抽一種狀態、維持 20 秒，暫停不推進，新世界重抽。抽到加速時水平速度為原本 1.5 倍，減速時為 0.5 倍，步行、蹲行與奔跑都套用；效果結束自動恢復原速度，不會反覆累乘。

致盲畫面與跳躍提升尚未套用；不能將此版視為四種效果都已完成。後續依 PLANS.md 的 E03～E04 執行 TDD 與全部前段回歸。
